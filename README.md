# CX32L003 OLED 电子钟

基于 **CX32L003**（Cortex-M0+）的桌面电子钟：DS1302Z 硬件走时 + SSD1306 OLED 显示 + ADC 四键操作 + 双闹钟 + 三路蜂鸣器。

---

## 1. 功能特性

| 功能 | 说明 |
|---|---|
| 硬件走时 | DS1302Z 内置 32.768kHz 晶振自行计时，MCU 只负责读取与显示 |
| 掉电保持 | 时间与闹钟配置均由 DS1302 后备电池维持，上电立即显示原时间 |
| 双闹钟 | 起床闹钟（间歇响、最长 60s、支持贪睡 5 分钟）；待办闹钟（响 3 声自动停） |
| 三路蜂鸣器 | 可切换 有源 A1(PA3) / 有源 A2(PB5) / 无源 P(PB4)，选择掉电保存 |
| 年月日 / 时分秒 / 星期 | OLED 四行显示，设置时当前字段闪烁 |
| 独立设置页 | 时间设置与闹钟设置分成两页，改闹钟不会影响走时 |
| 时钟突发读 | 一次事务读回 7 个时间寄存器，避免跨进位产生撕裂快照 |

## 2. 硬件资源与引脚

### 2.1 蜂鸣器（NPN 三极管低边驱动，高电平导通）

| 编号 | 引脚 | 类型 | 驱动方式 | 界面显示 |
|---|---|---|---|---|
| 1 | PA3 | 有源 | 给高电平即响 | `A1` |
| 2 | PB5 | 有源 | 给高电平即响 | `A2` |
| 3 | PB4 | 无源 | 输出约 2.7kHz 方波 | `P ` |

### 2.2 DS1302Z 实时时钟

| 信号 | 引脚 | 说明 |
|---|---|---|
| SCLK | PC3 | 串行时钟 |
| I/O | PC4 | 双向数据（写时输出、读时输入） |
| CE / RST | PC5 | 片选 |

### 2.3 其他

- OLED：SSD1306 128×64，软 I2C，4 行（y = 0 / 16 / 32 / 48），每行 16 个字符，字体 `asc2_1608`
- 按键：ADC 分压按键 K1~K4，扫描周期 10ms，支持单击 / 双击 / 长按 / 长按连发

## 3. 界面布局

| 行 | y | 内容 |
|---|---|---|
| 1 | 0 | 日期 + 星期，如 `2026-10-13 W2` |
| 2 | 16 | 时分秒，如 `14:30:00` |
| 3 | 32 | 状态 / 提示行（随状态变化） |
| 4 | 48 | 两个闹钟状态：`1 HH:MM  2 HH:MM` |

第 4 行中，闹钟 1 / 2 使能时显示 `1` / `2`，未使能显示 `-`。

## 4. 按键操作

K1 = MODE，K2 = UP，K3 = DOWN，K4 = ALARM

### 4.1 空闲状态（第 3 行提示 `K1:Time K4:Alm  `）

| 按键 | 作用 |
|---|---|
| K1 短按 | 进入**时间设置页**（从「年」开始） |
| K4 短按 | 进入**闹钟设置页**（从「闹钟1使能」开始） |

### 4.2 时间设置页（第 3 行提示 `Set:K1+ K2- K4X `）

字段顺序：**年 → 月 → 日 → 时 → 分 → 秒 → 星期**

| 按键 | 作用 |
|---|---|
| K1 短按 | 提交当前字段并进入下一字段；在「星期」上按下 = 写入 DS1302 并退出（只写时间） |
| K2 短按 / 长按连发 | 当前字段 +1 |
| K3 短按 / 长按连发 | 当前字段 -1 |
| K4 长按 | 放弃修改退出 |

该页显示的时间取自进入设置瞬间的编辑副本，不自动走时（正在校时，属预期行为）。

### 4.3 闹钟设置页（第 3 行提示 `Alm:K1+ K2- K4X `）

字段顺序：**闹钟1使能 → 闹钟1时 → 闹钟1分 → 闹钟2使能 → 闹钟2时 → 闹钟2分 → BEEP**

| 按键 | 作用 |
|---|---|
| K1 短按 | 提交当前字段并进入下一字段；在 **BEEP** 上按下 = 保存闹钟配置并退出（不碰时间） |
| K2 / K3 | 当前字段 +1 / -1（短按或长按连发） |
| K4 长按 | 放弃修改退出 |

该页的日期 / 时间行显示**实时走时**，可以边看时间边设闹钟；停在设置页时闹钟到点仍会正常触发。
走到 BEEP 字段时，第 3 行提示会被临时替换为 `BEEP:A1` / `BEEP:A2` / `BEEP:P `。

### 4.4 响铃与贪睡（此时其它按键被屏蔽，只响应 K1）

| 第 3 行提示 | 状态 | K1 短按 | K1 长按 |
|---|---|---|---|
| `ALARM! K1:Snoze ` | 起床闹钟响铃 | 贪睡（5 分钟后重响） | 停止 |
| `TODO!  K1:Stop  ` | 待办闹钟响铃 | 停止 | 停止 |
| `SNOOZE K1:Cncl  ` | 贪睡等待中 | 取消贪睡 | 停止 |

## 6. 配置存储（DS1302 内部 RAM）

从 `0xD0` 起连续 8 字节，掉电由后备电池保持：

| 索引 | 地址 | 含义 |
|---|---|---|
| 0 | 0xD0 | 魔数 `0xA5`（用于判断配置是否有效） |
| 1 | 0xD2 | 蜂鸣器选择（0 = A1 / 1 = A2 / 2 = P） |
| 2 | 0xD4 | 闹钟1 使能 |
| 3 | 0xD6 | 闹钟1 时 |
| 4 | 0xD8 | 闹钟1 分 |
| 5 | 0xDA | 闹钟2 使能 |
| 6 | 0xDC | 闹钟2 时 |
| 7 | 0xDE | 闹钟2 分 |

写 RAM 前关写保护（`0x8E = 0x00`），写后开写保护（`0x8E = 0x80`）。
魔数不匹配时写入默认值：蜂鸣器 = A1(PA3)，闹钟1 = 关闭 / 07:00，闹钟2 = 关闭 / 08:00。

## 7. 上电与掉电行为

1. 读取 RTC 时间并做有效性校验（月 1~12、日 1~31、时 ≤ 23、分 / 秒 ≤ 59、年 2000~2099；**故意不校验星期**，避免「从没设过星期」的正常走时被误判）
2. 仅当无效（首次上电 / 电池丢失 / 晶振停振）时才写一次默认时间 `2026-10-13 14:30:00 星期2`，并立即回读
3. 读取闹钟配置，魔数 `0xA5` 不匹配则写默认值
4. 进入主循环前立即绘制一帧，上电即显示电池保持的时间、日期与闹钟行

判「无效」的原理：DS1302 停振时秒寄存器 bit7（CH）= 1，读出会变成 80（> 59）；全新芯片寄存器为 0x00，月 = 0。两者都会落进上面的范围外。

掉电时，RTC 时间与闹钟配置均由 DS1302 的后备电池保持。

## 10. 开发约定（重要）

本工程的源文件（`Src/*.c`、`Drivers/**/*.c/.h`、`Inc/*.h`）均为 **GBK 编码 + CRLF 换行**。

修改时注意：**不要用按 UTF-8 处理的编辑器或工具整体改写这些文件**。一旦文件在 UTF-8 状态下被保存，所有中文注释会被替换成 `?` 且不可逆。
正确做法：在编辑器中用 **Reopen with Encoding → GBK** 打开，或用「按 GBK 读 → 局部替换 → 按 GBK 写回」的方式修改；改完用字节校验确认（文件中 `0x3F`（`?`）数量不异常、GBK 可正常解码、无孤立 LF）。
