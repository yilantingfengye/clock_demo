# CX32L003 OLED 时钟 · 闹钟功能说明与修改记录

> 工程：`f:\CX32L003\clock_demo`（CX32L003 + DS1302Z + SSD1306 OLED + ADC 按键 + 三路蜂鸣器）
> 本文档整理：功能说明、使用说明，以及本次改动过程中发现并修复的问题。

---

## 1. 概述

在原有 OLED 电子钟基础上新增**闹钟功能**：支持两路闹钟（起床闹钟 / 待办闹钟）与三选一蜂鸣器，配置掉电保存，全部通过 K1~K4 设置，复用工程既有文件结构。

---

## 2. 硬件资源与引脚映射

### 2.1 蜂鸣器（三路，均为 NPN 三极管低边驱动，高电平导通）

| 编号 | 引脚 | 类型 | 驱动方式 | 界面显示 |
|---|---|---|---|---|
| 1 | PA3 | 有源 | 给高电平即响 | `A1` |
| 2 | PB5 | 有源 | 给高电平即响 | `A2` |
| 3 | PB4 | 无源 | 输出约 2.7kHz 方波 | `P ` |

### 2.2 DS1302Z 实时时钟

| 信号 | 引脚 | 说明 |
|---|---|---|
| SCLK | PC3 | 串行时钟 |
| I/O | PC4 | 双向数据（写时输出、读时输入） |
| CE/RST | PC5 | 片选 |

### 2.3 其他

- OLED：SSD1306 128×64，软 I2C，4 行（y = 0 / 16 / 32 / 48），每行 16 个字符（字体 `asc2_1608`）。
- 按键：ADC 分压按键 K1~K4，扫描周期 10ms，支持单击 / 双击 / 长按 / 长按连发。

## 3. 功能说明

### 3.1 界面布局

| 行 | y | 内容 |
|---|---|---|
| 1 | 0 | 日期 + 星期，如 `2026-10-13 W2` |
| 2 | 16 | 时分秒，如 `14:30:00` |
| 3 | 32 | 状态 / 提示行（随状态变化，见 4.x） |
| 4 | 48 | 两个闹钟状态：`1 HH:MM  2 HH:MM` |

第 4 行中，闹钟 1 / 2 使能时显示 `1` / `2`，未使能显示 `-`。

### 3.2 走时方式

时间由 **DS1302Z 硬件自己走**（内部 32.768kHz 晶振 + 分频计数链，靠后备电池维持），MCU 不参与计时，只负责读取与显示。主循环每 500ms 用**时钟突发读**（命令 `0xBF`）一次性读回 7 个时间寄存器，保证 7 个字节来自同一时刻。

### 3.3 两类闹钟

| 类型 | 对应 | 响铃方式 | 贪睡 |
|---|---|---|---|
| 起床闹钟 | 闹钟 1 | 响 500ms / 停 500ms，最长 60 秒自动停 | 支持，5 分钟后重响 |
| 待办闹钟 | 闹钟 2 | 响 200ms / 停 200ms，共 3 声自动停 | 不支持 |

同一分钟内只触发一次（用触发时的时 / 分记录防重复）。

### 3.4 蜂鸣器选择

三路蜂鸣器可在闹钟设置页内切换，选择结果写入 DS1302 RAM 掉电保存。

## 4. 使用说明（K1 = MODE，K2 = UP，K3 = DOWN，K4 = ALARM）

### 4.1 空闲状态

第 3 行提示：`K1:Time K4:Alm  `

| 按键 | 作用 |
|---|---|
| K1 短按 | 进入**时间设置页**（从"年"开始） |
| K4 短按 | 进入**闹钟设置页**（从"闹钟1使能"开始） |

### 4.2 时间设置页

第 3 行提示：`Set:K1+ K2- K4X `

字段顺序：**年 → 月 → 日 → 时 → 分 → 秒 → 星期**

| 按键 | 作用 |
|---|---|
| K1 短按 | 提交当前字段并进入下一字段；在"星期"上按下 = **写入 DS1302 并退出**（只写时间） |
| K2 短按 / 长按连发 | 当前字段 +1 |
| K3 短按 / 长按连发 | 当前字段 -1 |
| K4 长按 | 放弃修改退出 |

编辑时当前字段闪烁；该页显示的时间取自进入设置瞬间的编辑副本，**不会自动走时**（这是预期的：正在校时）。

### 4.3 闹钟设置页

第 3 行提示：`Alm:K1+ K2- K4X `

字段顺序：**闹钟1使能 → 闹钟1时 → 闹钟1分 → 闹钟2使能 → 闹钟2时 → 闹钟2分 → BEEP（蜂鸣器）**

| 按键 | 作用 |
|---|---|
| K1 短按 | 提交当前字段并进入下一字段；在 **BEEP** 上按下 = **保存闹钟配置并退出**（不碰时间） |
| K2 / K3 | 当前字段 +1 / -1（短按或长按连发） |
| K4 长按 | 放弃修改退出（蜂鸣器切换也不生效） |

该页的日期 / 时间行显示的是**实时走时**，可以边看时间边设闹钟；停在设置页时闹钟到点仍会正常触发。

走到 BEEP 字段时，第 3 行的提示会被临时替换为 `BEEP:A1` / `BEEP:A2` / `BEEP:P `。

### 4.4 响铃与贪睡

此时其它按键被屏蔽（只响应 K1）。

| 第 3 行提示 | 状态 | K1 短按 | K1 长按 |
|---|---|---|---|
| `ALARM! K1:Snoze ` | 起床闹钟响铃 | 贪睡（5 分钟后重响） | 停止 |
| `TODO!  K1:Stop  ` | 待办闹钟响铃 | 停止 | 停止 |
| `SNOOZE K1:Cncl  ` | 贪睡等待中 | 取消贪睡 | 停止 |

## 5. 配置存储（DS1302 内部 RAM）

从 `0xD0` 起连续 8 字节，掉电由后备电池保持：

| 索引 | 地址 | 含义 |
|---|---|---|
| 0 | 0xD0 | 魔数（`0xA5`，用于判断配置是否有效） |
| 1 | 0xD2 | 蜂鸣器选择（0=A1 / 1=A2 / 2=P） |
| 2 | 0xD4 | 闹钟1 使能 |
| 3 | 0xD6 | 闹钟1 时 |
| 4 | 0xD8 | 闹钟1 分 |
| 5 | 0xDA | 闹钟2 使能 |
| 6 | 0xDC | 闹钟2 时 |
| 7 | 0xDE | 闹钟2 分 |

写 RAM 前关写保护（`0x8E=0x00`），写后开写保护（`0x8E=0x80`）。魔数不匹配时写入默认值：蜂鸣器 = A1（PA3），闹钟1 = 关闭 / 07:00，闹钟2 = 关闭 / 08:00。

## 6. 上电与掉电行为

上电流程（`main()`）：

1. `DS1302_read_realTime()` 读取 RTC 时间；
2. **有效性校验**：月 1~12、日 1~31、时 ≤23、分 / 秒 ≤59、年 2000~2099（**故意不校验星期**，避免"从没设过星期"的正常走时被误判）；
3. 仅当无效（首次上电 / 电池丢失 / 晶振停振）时才写一次默认时间 `2026-10-13 14:30:00 星期2`，并立即回读；
4. 读取闹钟配置，魔数 `0xA5` 不匹配则写默认值；
5. `OLED_DisPlay_On()` 之后立即绘制一帧，上电即显示电池保持的时间、日期与闹钟行，无需等主循环周期。

掉电时，RTC 时间与闹钟配置均由 DS1302 的后备电池保持。

判"无效"的原理：DS1302 停振时秒寄存器 bit7（CH）= 1，读出会变成 80（> 59）；全新芯片寄存器为 0x00，月 = 0。两者都会落进上面的范围外。

## 7. 本次修改相关的问题与修复记录

### Bug 1：闹钟设置页里时间不走时

**现象**：进入闹钟设置页后，第 2 行的时分秒停在进入那一刻，不跳动。

**根因**（两处叠加）：
1. 主循环中 500ms 的 `DS1302_read_realTime()` 被 `if (s_set_field == SET_NONE)` 门控 → 设置页里 `TimeData` 根本不更新；
2. 设置态下 `display_time()` 只重绘"当前闪烁字段"，时间字段从进页那一帧起就不再刷新。

**修复**：
1. 把读时移到门控之外，任何时候都刷新 `TimeData`；闹钟页额外置 `need_refresh` 让屏幕跟着刷新（时间设置页仍不动 `s_edit` 编辑副本）；
2. 当前字段属于闹钟页（`field >= SET_AL1_EN`）时，先整屏重画再叠加闪烁字段。

**附带修掉的隐患**：闹钟匹配用的是 `TimeData` 的时 / 分，之前停在任一设置页时 `TimeData` 不更新 → **待在设置页里闹钟到点不会响**。

### Bug 2：改闹钟会连带把时间写回去

**现象**：只想改闹钟，也必须走完 年→…→星期→闹钟→BEEP 全部字段；最后按下 K1 会把进入设置瞬间的**时间副本**整体写回 DS1302，造成走时被回拨。

**根因**：时间与闹钟被耦合在同一个"一页连续遍历"的设置状态机里，提交动作同时包含"写时间 + 存配置"。

**修复**：拆成两页，页别由当前字段区间推断，不新增状态变量：
- 时间页 `SET_YEAR..SET_WEEK`：K1 短按进入，走到"星期"按 K1 → **只写时间**后退出；
- 闹钟页 `SET_AL1_EN..SET_BEEP`：K4 短按进入，走到"BEEP"按 K1 → **只保存闹钟配置**（不再调用 `DS1302Z_SetTimeFromDec`）后退出。

### Bug 3：每次上电都覆盖电池保持的时间

**现象**：DS1302 带后备电池，掉电走时应保持，但每次上电时间都被重置为固定的 `2026-10-13 14:30:00`。

**根因**：`main()` 里无条件执行 `default_time = 2026-10-13 14:30:00` + `DS1302Z_SetTimeFromDec()`。

**修复**：改为"先读 → 校验有效 → 仅无效才写默认值并回读"，并在进入主循环前立即绘制一帧（见第 6 节）。

### Bug 4：逐个寄存器读 RTC 可能得到撕裂快照

**现象（潜在）**：秒、分、时、日等分别用 7 次独立事务读取，若两次读之间恰好跨过进位（例如先读到秒 = 59，再读分时已翻到下一分），会得到"半新半旧"的时间，偶发显示错 1 分钟。

**修复**：`DS1302_read_time()` 改为**时钟突发读**（命令 `0xBF`，一条事务连续读回 7 个字节）。`read_time[]` 布局与 BCD 解码不变，上层零影响；`DS1302_Read_rig()` 仍保留给 RAM 配置读写和 CH 位检查使用。

### 其他相关修复（同一工程，较早）

- **`OLED_ShowString()` 换行 bug**：原换行条件是 `x > 128 - size1` 且换行后 `y += 2`，导致长度 16 的字符串末尾字符被画到下一行行首、覆盖第一个字符（表现为 `0123456789ABCDEF` 开头的 `0` 消失）。已修正为换行条件 `x >= 128`、换行时 `y += size1`。

## 9. 开发约定（重要）

本工程源文件（`main.c`、`*.c`、`*.h`）均为 **GBK 编码 + CRLF 换行**。

修改时注意：**不要用会改变文件编码的工具直接整体改写**（会把中文注释按 UTF-8 重编码，造成全文注释损坏且不可逆）。应使用"按 GBK 读 → 局部替换 → 按 GBK 写回"的方式，改后用字节校验确认：文件中 `0x3F`（`?`）数量不异常、GBK 可正常解码、无孤立 LF。
